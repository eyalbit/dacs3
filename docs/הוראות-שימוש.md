# DACS-3.0 - הוראות שימוש מהירות 🚀

## 🎯 הרצה מהירה (3 דקות)

### צעד 1: וידוא דרישות
```powershell
# בדוק שיש Node.js
node --version

# בדוק שיש Python
python --version

# אם אין - התקן מ:
# Node.js: https://nodejs.org/

```

### צעד 2: התקנת תלויות (פעם אחת בלבד)
```powershell
cd scraper-ts

npx playwright install chromium
cd ..
```

### צעד 3: הגדרת משתני סביבה
צור קובץ `.env` בתיקיה הראשית:

```env
BARCHART_EMAIL=eb.bitan@gmail.com
BARCHART_PASSWORD=100%Gamba
BARCHART_LOGIN_URL=https://www.barchart.com/login
BARCHART_SCREENER_URL=https://www.barchart.com/stocks/stocks-screener?viewName=filter_view&screener=478448

GEMINI_API_KEY=your-gemini-api-key-here
```

### צעד 4: הרצת המערכת! 🎉
```powershell
.\run-full-workflow.ps1
```

או בBAT (אם PowerShell לא עובד):
```cmd
run-full-workflow.bat
```

## ⚙️ הגדרות מתקדמות

### שינוי Delta Range
ערוך את `csv_united.py` בתחילת הקובץ:

```python
DELTA_MIN = 0.07     # שנה ל-0.05 למשל
DELTA_MAX = 0.21     # שנה ל-0.30 למשל
```

### שליחת מייל אוטומטית
ערוך את `csv_united.py`:

```python
AUTO_SEND_EMAIL = True    # שנה ל-True כדי לשלוח מייל
EMAIL_TO = 'eb.bitan@gmail.com'
```

ב-`.env` הוסף:
```env
GMAIL_USER=your-email@gmail.com
GMAIL_PASSWORD=your-app-password
```

**הערה:** צריך Gmail App Password, לא סיסמה רגילה!
יצירה: https://myaccount.google.com/apppasswords

## 🐛 פתרון בעיות נפוצות

### ❌ "python not found"
**פתרון:** התקן Python מ-https://www.python.org/

### ❌ "npm not found"
**פתרון:** התקן Node.js מ-https://nodejs.org/

### ❌ "Playwright browsers not installed"
**פתרון:**
```powershell
cd scraper-ts
npx playwright install chromium
cd ..
```

### ❌ "Login failed" (Barchart)
**פתרון:**
1. בדוק username/password ב-`.env`
2. נקה session cache:
```powershell
cd scraper-ts
npm run screener -- --clear-session
cd ..
```

### ❌ "GEMINI_API_KEY not found"
**פתרון:** 
1. צור `.env` בתיקיה הראשית
2. הוסף: `GEMINI_API_KEY=your-key-here`
