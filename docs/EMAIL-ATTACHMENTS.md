```python
# After: attach all files from folder
asset_folder = os.path.dirname(html_file_path)

files_to_attach = []
if os.path.isdir(asset_folder):
    for item in os.listdir(asset_folder):
        item_path = os.path.join(asset_folder, item)
        if os.path.isfile(item_path):
            files_to_attach.append(item_path)

print(f'  Attaching {len(files_to_attach)} files...')
for file_path in files_to_attach:
    file_name = os.path.basename(file_path)
    print(f'    - {file_name}')
    
    with open(file_path, 'rb') as attachment:
        part = MIMEBase('application', 'octet-stream')
        part.set_payload(attachment.read())
    
    encoders.encode_base64(part)
    part.add_header('Content-Disposition', f'attachment; filename={file_name}')
    msg.attach(part)
```

## איך להפעיל שליחת מייל?

### 1. הגדר את `.env`:
```env
GMAIL_USER=your-email@gmail.com
GMAIL_PASSWORD=your-app-password
```

**חשוב:** צריך Gmail App Password, לא סיסמה רגילה.  
**קישור:** https://myaccount.google.com/apppasswords

### 2. הפעל שליחת מייל אוטומטית:

ערוך `csv_united.py` שורה 50:
```python
AUTO_SEND_EMAIL = True  # Change from False to True
```

### 3. הרץ את המערכת:
```bash
python3.14 csv_united.py
```

המערכת תשלח מייל אוטומטית אחרי כל ניתוח.

## פתרון בעיות

### בעיה 1: "Missing email credentials"
**פתרון:** ערוך `.env`:
```env
GMAIL_USER=your-email@gmail.com
GMAIL_PASSWORD=your-app-password
```

### בעיה 2: "Email authentication failed"
**סיבה:** שימוש בסיסמה רגילה במקום App Password
