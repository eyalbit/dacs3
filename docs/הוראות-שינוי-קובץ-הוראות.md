# הוראות לשינוי כללי המסחר במערכת DACS 3.0

## עקרון חשוב: היכן לבצע שינויים

כדי להבטיח שהמערכת תפעל לפי הכללים שלך, יש **3 מקומות** שבהם צריך לבצע שינויים:

---

## 1. קבצי ההוראות (agent-docs)
**📁 תיקייה:** `agent-docs/`

### קבצים עיקריים:
- **`אנגלית-כללי מסחר DACS-3.0 עבור AGENT.txt`** - כללי המסחר העיקריים
- **`csv file filter.txt`** - כללי סינון ה-CSV
- **קבצים נוספים:** `.docx` עם פרוטוקולים מפורטים

### מתי לשנות?
- שינוי בכללי Delta
- שינוי בכללי DTE
- שינוי בכללי Margin
- שינוי בכללי Open Interest
- כל שינוי אחר בלוגיקה העסקית

### דוגמה:
רוצה לשנות את ה-Delta המינימלי מ-0.07 ל-0.10?

**לפני:**
```
Target Delta between 0.08 and 0.15
```

**אחרי:**
```
Target Delta between 0.10 and 0.15
```

## 2. הגדרות Python (csv_united.py)
**📄 קובץ:** `csv_united.py`  
**📍 מיקום:** שורות 38-58 (סעיף `CONFIGURATION`)

### משתנים שאפשר לשנות:

```python
# ===== Options Filtering Rules =====
DELTA_MIN = 0.07                     # מינימום Delta
DELTA_MAX = 0.21                     # מקסימום Delta
MIN_OPEN_INTEREST = 500              # מינימום Open Interest
MIN_DTE_DAYS_SHORT_LEG = 3          # מינימום ימים לפקיעת Short Leg

# ===== Email Configuration =====
EMAIL_TO = 'your-email@gmail.com'    # כתובת מייל לדוחות
AUTO_SEND_EMAIL = False              # שליחה אוטומטית של מייל

# ===== Asset Selection =====
DEFAULT_ASSET = 'spy'                # נכס ברירת מחדל
```

### מתי לשנות?
- רוצה לשנות פילטר Delta מהיר (לפני שGemini רואה את הנתונים)
- רוצה לשנות הגדרות מייל
- רוצה לשנות את נכס ברירת המחדל

## תרשים זרימה: איך המערכת עובדת

```
1. קבצי CSV מ-Barchart
         ↓
2. Python מבצע סינון ראשוני (csv_united.py)
   - מסנן לפי Delta (DELTA_MIN - DELTA_MAX)
   - מסנן לפי DTE (MIN_DTE_DAYS_SHORT_LEG)
   - יוצר קובץ merged_filtered_options.csv
         ↓
3. Python שולח ל-Gemini:
   - קובץ ה-CSV המסונן
   - קבצי הוראות מ-agent-docs (כ-system instructions)
   - Prompt עם הכללים (כולל תאריך היום)
         ↓
4. Gemini מנתח ובונה עסקאות
   - לפי הכללים מ-agent-docs
   - לפי ההוראות מה-Prompt
   - מחזיר טבלאות עם עסקאות מומלצות
         ↓
5. Python יוצר HTML report
   - שומר כקובץ HTML
   - (אופציונלי) שולח במייל
```

## כללי אצבע לשינויים

### ✅ DO - כן לעשות:

1. **לשנות בכל 3 המקומות** אם השינוי משפיע על הלוגיקה העיקרית
   - דוגמה: שינוי Delta → צריך לעדכן גם Python וגם agent-docs וגם Prompt

2. **לבדוק אחרי שינוי** עם `--merge-only`:
   ```bash
   python csv_united.py --merge-only
   ```
   בדוק שה-CSV המסונן תקין.

3. **לתעד שינויים** בקבצי README או מסמכי הוראות

### ❌ DON'T - לא לעשות:

1. **לא לשנות רק במקום אחד** אם השינוי הוא קריטי
   - אם שינית בPython, חובה לעדכן גם את agent-docs!

2. **לא לשנות ערכים ישירות בקוד** מחוץ לסעיף `CONFIGURATION`
   - כל הקבועים צריכים להיות בראש הקובץ

3. **לא לשנות את פורמט ה-CSV** בלי לעדכן את האינדקסים:
   ```python
   COL_EXPIRATION_DATE = 0
   COL_CALL_DELTA = 8
   COL_STRIKE = 11
   ```
