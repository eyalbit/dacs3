# Strategy Core Definition (DACS-3.0)
- This is a weekly diagonal/calendar-oriented strategy.
- Goal: Low Credit or small Debit, utilizing Backwardation, based on a Positive Vega position (where the Long leg can benefit from IV expansion).


# Step-by-Step Execution Protocol


## Step 1: Direction & Asset Filters
- Default side: CALL. Build the strategy on the Call side unless the user explicitly requested the PUT side.
- Open Interest (OI): Ensure OI > 500 for both legs to guarantee liquidity.
- Implied Volatility (IV): Target IV between 25% to 30% (Acceptable up to 35% if other parameters are optimal).


## Step 2: Short Leg Selection (CRITICAL - DTE VALIDATION REQUIRED)
- Expiration: Weekly expiration only (the upcoming Friday). Days to Expiration (DTE) must be between 3 to 7 days.
  - CRITICAL: You MUST calculate the DTE for each potential Short Leg before selecting it.
  - CRITICAL: REJECT any Short Leg with DTE < 3 days or DTE > 7 days.
  - If DTE = 3: Position must be opened on Tuesday.
  - If DTE = 4: Position must be opened on Monday.
  - Example: If today is July 30, 2026, then:
    * July 31, 2026 expiration (DTE=1) = INVALID (too soon)
    * August 1, 2026 expiration (DTE=2) = INVALID (too soon)
    * August 2, 2026 expiration (DTE=3) = VALID (minimum)
    * August 5, 2026 expiration (DTE=6) = VALID
    * August 6, 2026 expiration (DTE=7) = VALID (maximum)
    * August 7, 2026 expiration (DTE=8) = INVALID (too far for Short Leg, but valid for Long Leg)
- Strike Selection by Delta:
  - Standard Condition: Target Delta between 0.08 and 0.15. Aim for the middle (~0.11) or slightly lower. Absolute maximum Delta allowed is 0.16.
  - Earnings Condition: If the company reports Earnings during the Short leg's week, reduce risk -> Target Delta close to 0.08 (Absolute minimum allowed is 0.07).
- Expected Move (EM) Filter: 
  - Ensure that: Short Strike > (Current Stock Price + Expected Move).
- Print the original line, with its title, from which you took the information for LEG SHORT


## Step 3: Long Leg Selection
- Expiration: The exact next weekly expiration immediately following the Short leg's expiration (+7 days from Short expiration).
- Strike Selection (Margin requirement): Choose a strike that results in a buying power reduction (Margin/Collateral) between $500 to $1,000. (Absolute maximum allowed for an exceptional setup is $1,500).
- Print the original line, with its title, from which you took the information for LEG LONG


## Step 4: Position Math & Risk/Reward Filters
Calculate and validate the following metrics for the combined position:


1. Premium Cost/Gain:
   - For CREDIT: Must be between 2% to 4% of the Margin requirement (No more than 4%).
   - For DEBIT: Must be as low as possible, with an absolute maximum of $60 per CONTRACT (multiply per-share cost by 100).
     * CRITICAL: Each options contract represents 100 shares
     * Example: If Debit is $0.55 per share, total cost = $0.55 × 100 = $55 per contract ✅ VALID
     * Example: If Debit is $1.50 per share, total cost = $1.50 × 100 = $150 per contract ❌ INVALID (exceeds $60)


2. Bid-Ask Spread:
   - The Bid-Ask spread for each individual leg must be tight: 3-5 cents for lower-priced stocks, maximum 10 cents for high-priced stocks.


3. Fast Ratio Formula:
   - For Credit Positions: Fast Ratio = (Mid Long Cost + Credit) / Margin
   - For Debit Positions: Fast Ratio = (Mid Long Cost - Debit) / Margin
   * Express the result as a percentage (X%).


4. Term Structure:
   - Identify if the position is in Backwardation (preferred) or Contango.
